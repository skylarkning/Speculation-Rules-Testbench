# Version 1.4.0

Initial Mozilla Add-ons release.

- Detects and classifies inline Speculation Rules on the inspected page.
- Identifies Firefox Milestone 1-compatible list, immediate, same-origin
  prefetch targets.
- Captures prefetch and navigation request evidence in a DevTools panel.
- Runs a blocked-prefetch control against the same locked source/target pair.
- Records cache and Navigation Timing signals without treating a single run as
  a performance benchmark.
- Exports a privacy-sanitized JSON report.
- Opens structured GitHub bug-report and feature-request forms.
