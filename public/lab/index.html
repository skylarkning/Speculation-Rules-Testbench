01 · Prepare

One target, two conditions

Both runs open the same static document with a unique query string. The enabled run first injects an immediate list rule; the control does not. Unique URLs keep the two runs from warming each other. 

{
  "prefetch": [{
    "source": "list",
    "urls": ["./target.html?run=…"],
    "eagerness": "immediate"
  }]
}
